The collection contains examples for authentication, shopping, offer pricing, order creation/view/cancellation, seat maps, ancillary lookup, adding/removing seats and ancillaries, fulfillment, passenger updates, repricing, reshop, exchange, synchronization and unused tickets.

For the airline extras work, start with the `Offers GetAncillaries /v2` and `Orders Change /v1 Add Ancillaries` examples, then review their offer pricing and fulfillment dependencies.

These are retained January 2025 reference examples. The files' setup instructions and scripts are documentation, not instructions to execute requests. Saving the collection does not enable NDC booking or establish airline entitlements for the current account.
