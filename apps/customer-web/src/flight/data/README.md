# Airport directory

`airports.json` is a snapshot of [OurAirports airports.csv](https://ourairports.com/data/) and [GeoNames cities5000](https://www.geonames.org/export/). OurAirports airport coordinates and mapped GeoNames city-centre coordinates are used to show approximate straight-line distances in airport suggestions. Some well-known airport groups use a curated metro label and centre reference so the airport's local municipality does not split the destination city (for example, KUL and SZB are grouped as Kuala Lumpur; PEN is labelled Penang). A distance is omitted when no suitable city-centre reference can be mapped. GeoNames data is licensed under CC BY 4.0; OurAirports data is public domain. Regenerate it with `scripts/update-airport-directory.ps1`.

The snapshot includes every open airport with a three-letter IATA code in the source. Closed airports and balloonports are excluded. The source's `keywords` help match alternate city names and nearby airports, such as Tokyo and Narita. `scheduled` reflects the source's scheduled airline service flag. A city-centre distance is omitted when no suitable centre can be associated through the airport name, municipality, nearby major city, or curated metro mapping. This directory helps customers find an airport code; it does not represent Sabre route coverage or fare availability. Sabre validates each search separately.
